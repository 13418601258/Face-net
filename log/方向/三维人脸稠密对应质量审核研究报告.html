三维人脸稠密对应质量审核与人工复核筛选

01

主张

拟研究主张：不同类型的对应失败会留下不同的局部几何与映射一致性信号。把这些可解释信号输入面片级或顶点级神经网络，可以在稠密真值不可用或不完整时，估计对应输出的风险、定位可疑区域，并将有限人工复核资源优先分配给高风险结果。

该系统作为对应生成模型之后的质量审核器。它预测质量与失败风险，不通过质量分数反向驱动对应变形。

图 1. 计划中的审核流程。质量分数应保留多维输出，不能只依赖一个加权总分。

1.1 研究对象与目标边界

研究对象

输出后的质量控制

输入是已有对应算法产生的网格形变或稠密映射；输出是样本级风险、局部风险热图、可能失败类型和复核建议。

不作为目标

不直接优化对应

不把紧致性、Sobolev 能量或质量分类分数直接当作对应网络的训练目标，避免质量代理成为错误的优化方向。

1.2 三个概念不能混为一谈

对象数学含义本研究中的用途不能推出什么
Sobolev 度量定义形变速度的内积，并可通过路径长度定义形状间距离理解平滑形变、正则性和形状空间邻近关系不能单独证明语义对应正确或没有自交
几何能量 / 质量泛函对给定映射 f 计算一个或多个失真量作为审核特征或独立门禁不自动满足距离公理，也不代表整体质量
曲面拓扑连通、边界、孔洞、亏格等离散结构检测网格结构改变及映射邻接异常标准人脸拓扑大多相同，Betti 数难区分细微对应错误
关键定位：“度量诱导拓扑”指距离在形状空间上定义邻域；它不是用度量推导人脸表面的拓扑类别。若把参数化映射商掉，甚至可能把本研究要检查的对应差异一并抹去。

1.3 候选几何探针

公式中的各项先作为独立的可解释检查量，不预先合并成单一质量分。

E_strain(f) = ∫_M || log(ḡ^(-1/2) g_f ḡ^(-1/2)) ||_F² dA_ḡ E_curv(f) = ∫_M || II_f - IĪ ||²_(ḡ, ambient) dA_ḡ E_collision(f) = 非邻接面片相交 / 穿透深度 / 相交面积的检测或惩罚 q_geom(f) = [E_strain, E_curv, E_collision, 面片退化率, 局部 Jacobian 奇异值, 法向异常率]
内在几何

度量应变

g_f=f*δ 描述形变后的第一基本形式；对数项总结局部主方向拉伸。它对坐标表述较稳健，但纯等距弯曲可能不明显。

外在几何

第二基本形式

反映弯曲差异。比较前需要统一刚体坐标、参数化与法向方向，并区分合法表情弯曲和错误形变。

有效性

碰撞与退化

统计自交、穿透、近零面积和极端拉伸。软碰撞惩罚不能替代显式的三角形相交检测。

另一个 Sobolev 量：路径平滑性

G_f(h,k) = ∫_M [⟨h,k⟩ + ℓ²⟨∇^f h, ∇^f k⟩] dA_f d_S(F₀,F₁) = inf_{f(0)∈F₀, f(1)∈F₁} ∫₀¹ √G_f(f_t,f_t) dt

这是形变速度上的度量及其路径距离，和上面的静态 E_strain(f) 不是同一个东西。Sobolev 论文证明其特定形状空间中，至少达到 H¹ 强度可避免测地距离退化为零；但低阶 Sobolev 距离不必控制点的最大位移。落到人脸对应时，还必须注意：对 Diff(M) 取商会忽略参数化，而参数化正是对应信息的一部分。

步骤

S0

固定对象表示与审核范围 已执行 · 2026-11-14

第一轮限定共享模板拓扑上的人脸网格及对应/形变结果；只读取已解压的 AST-Face。以 ast001 中性脸固定编号与连接关系，以每个身份自己的中性脸作为表情形变参考。保留个体尺度，每个身份仅拟合一次无反射刚体变换并保存正逆参数，不改写、平滑或修复原始网格；重采样及点云重建暂不纳入。

实测：ast001–ast020 共 320 个网格、300 个形变数组、320 个关键点文件，共 940 个资产；320 个样本均通过本轮输入检查。网格均为 33,390 顶点、66,190 三角面，有序拓扑哈希一致；包含 590 条边界边、2 个边界环，允许开放边界，未检出退化面、重复面、非流形边、绕向冲突或未使用顶点。形变与“表情减中性”最大分量误差为 1.191×10−7 原始单位，刚体正逆变换最大分量误差为 3.553×10−15。

固定划分：ast001–ast015 为开发集（240 样本），ast016–ast020 为留出集（80 样本）；同一身份的后续扰动与随机种子继承其划分。中性脸与六种基本表情共 140 个样本作为首轮探针验证子集；留出数据本轮只检查完整性，不用于阈值选择。

限制：关键点均为 84 点，其包围盒对角线与网格之比约为 54.93–104.64；此比值不是精确的单位换算系数，暂不自动缩放或作为独立真值。尚未接入真实模型预测，也未进行自交、翻折、顶点邻域流形性或语义对应验证；S0 通过只说明可以开展 S1，不代表审核方法已有效。

复现与输出：项目根目录运行 python code/run_quality_s0.py。已通过 5 项针对性测试及导出文件哈希、身份隔离、变换检查。详见 输入协议、资产清单、逐样本检查、检查汇总、正逆变换及 身份划分。

S1

实现确定性质量探针 已完成 · 2026-11-15

对 ast001–ast020 的全部 320 个状态，以每个身份的中性脸为参考，计算面片曲面 Jacobian 的两个奇异值、面积比、三条边长比、法向点积/夹角和退化统计；每个样本另存面片级压缩数组。局部曲面 Jacobian 按 3×2 切平面映射处理，不使用普通三维行列式。

几何实测：320/320 个样本可计算，0 个无效 Jacobian，0 个退化目标面；中性脸自比较的加权奇异值和面积比均为 1、法向角为 0。300 个表情状态中，法向夹角超过 45° 的面片累计 489,326 个，法向点积为负的面片累计 195,268 个；加权 sigma_min 的中位数为 0.885，加权 sigma_max 的中位数为 1.170，加权面积比中位数为 1.024。不同表情均出现这些变化，说明它们是候选特征，不能直接当作失败标签或翻折证明。各表情汇总见 状态汇总。

自交实测：采用中位数切分 BVH 做宽相位，再用 float64 三角形 SAT 与线段-平面/重心坐标窄相位；共享顶点或边的相邻面片被排除。320 个网格产生 7,233,252 个宽相位候选对，其中 154,305 个严格穿越候选、102,905 个接触候选、0 个共面重叠。结果对已知相交/不相交/共面/共享边样例、随机网格的 BVH 与暴力集合对比均通过；刚体变换不改变面片对集合。由于不同身份的中性网格结果差异很大，这些面片对仍是需要可视化和拓扑复核的几何候选，不直接作为对应错误标签。

对应探针边界：当前没有真实模型的前向/反向映射，因此覆盖率和循环一致性记为 not_applicable；自交检测判断的是单个输出网格的几何有效性，不是对应语义正确性。

复现与输出：运行 python code/s1_probes.py --all-states 计算几何探针，运行 python code/run_self_intersection.py 执行自交筛查。详见 S1 汇总、逐样本探针、自交汇总、逐网格自交统计、面片对和 code/reports/quality_audit_s1/face_metrics/ 面片数组；使用 python -m unittest discover -s code -p "test_s1_probes.py" -v 与 python -m unittest discover -s code -p "test_self_intersection.py" -v 可复核测试。

S2

制造可控错误并验证几何、映射与语义探针 已完成 · 2026-11-20

在每个身份六种基本表情的共享索引映射上，注入局部压扁、切平面内局部折叠、局部顶点置换、平滑漂移、重复目标映射和映射覆盖缺失六类错误，各三档强度；以中性自映射、未扰动表情和共同刚体变换作正常控制。受扰顶点相邻面片构成已知定位区域，开发/留出身份沿用 S0 划分，固定几何门槛，不用留出身份调参。缺失映射区域不使用占位坐标计算对应误差或几何探针结果，相关字段明确记为不适用。

几何与映射探针规模：共 2,320 条样本记录，其中 2,160 个扰动案例（六类各 360；每类开发集 270、留出集 90）、120 个干净表情控制、20 个中性自映射和 20 个刚体不变性控制；区域定位表共 13,920 行。三个已知自交正控均找回预设相交面片对。按三档强度平均，新增应变告警的受影响面片召回率，局部压扁为开发 89.8%、留出 73.4%，局部置换为 86.5%、88.4%，局部折叠为 57.6%、52.2%；法向反转对折叠的召回约 32.9%、33.3%。平滑漂移的应变召回仅 3.9%、3.2%，确认局部几何探针对保形偏移存在盲点。覆盖缺失和重复映射探针在合成案例中均为 100% 区域召回、0 区外误报，但这属于实现正控，不是现实模型预测性能。

新增语义点探针：从官方 84 点接入 8 个锚点（双眼内外角、双嘴角、下巴、鼻尖），计算锚点两两距离变化、刚体对齐残差和缺失数量。全量处理 120 个正常中性→表情对、3,240 条点级扰动（交换、漂移、缺失三类各三档、三种子）及 40 个正常控制。共同刚体变换的最大特征差为 4.9×10−16；留出身份的锚点交换三档均有 100% 超过开发集正常 95% 阈值，说明明显语义错配可检出。小幅漂移的响应较弱，最高强度只有 5.6% 超过该阈值；缺失点主要由 missing_anchor_count 报告，不能靠距离变化替代完整性检查。

坐标边界：官方 landmark 坐标系与最终 Standardized Meshes 尚未得到可靠变换。简单包围盒校准后，20 个身份均未达到面片投影可用阈值，因此本轮语义探针是样本级/点集级特征，不能输出可靠的面片热图，也不把官方点文件当作独立绝对真值。S2 已完成“探针定义、可计算性、正常不变性、合成错误响应、身份/种子稳定性和缺失边界”四项工作；尚未证明探针能预测真实模型质量。详见 几何/映射汇总、几何逐样本结果、语义探针汇总、正常点探针、点级扰动和 投影诊断。运行 python code/s2_experiment.py 与 python code/s2_point_probes.py 可复现。

S3

接入真实模型并定义“需要人工复核”的监督目标 待执行 · S3 入口

S3 不再重新定义探针，而是把 S2 已完成的几何、映射完整性和 8 点语义探针接到真实模型输出上。这里的“提供 DECA 模型”不是手工制作模型：DECA 本身是官方代码、预训练神经网络权重、FLAME/landmark 资源和配置组成的模型包。3DDFA_V2 的官方仓库同样提供代码、weights/*.pth 预训练权重和示例输入，但 examples/results 只是结果目录占位，没有可直接使用的批量 .obj/.ply 推理数据，因此必须运行官方推理脚本生成输出。第一轮可以只提交运行后的输出；若要保证完整复现，再保存代码版本、权重文件校验值、FLAME/3DMM 资源版本和运行配置。第一轮固定先用 3DDFA_V2 跑通读取器和探针；它官方示例完整、OBJ/PLY 导出明确且推理速度快。DECA 放到第二轮作为跨模型泛化检查。这个顺序是工程和复现选择，不表示 3DDFA_V2 的重建质量一定优于 DECA。每个样本必须保存输入、模型输出、模型版本、随机种子和相机/参数，不能只保存一张结果截图。

第一轮最小规模：20 个身份，每个身份 3 个输入状态（中性、一个表情或姿态变化、一个较困难输入），共 60 个模型输出；其中 ast001–ast015 或前 15 个身份用于开发，另外 5 个身份只作留出。先跑一个模型；格式稳定后再跑第二个模型，第二个模型的身份划分必须保持一致。

需要保存的文件：每个样本至少包含输入图像或输入网格、输出网格顶点 vertices.npy、面片 faces.npy、模型参数 params.npz/json、相机内外参（若模型使用）、84/68/478 点（若模型提供）以及 metadata.json。元数据记录 sample_id、identity_id、model_name、model_version、seed、输入路径和处理状态。权重不必复制进每个样本目录；可在单独的模型清单中记录权重路径、SHA-256、代码提交号和配置文件。

两种对应格式：DECA、3DDFA_V2 这类参数化模型通常输出固定 3DMM/FLAME 模板。此时可以把同一模板顶点编号视为隐式拓扑对应，令 forward_map[i]=i、inverse_map[i]=i；它适合检验几何和语义探针，但覆盖率和循环一致性是先验恒等映射，不能当作真实稠密对应模型的预测能力。若使用真正的对应模型，则必须另存前向映射 f：每个源点对应目标顶点索引，或目标三角形索引加三角形内重心坐标；有反向映射时另存 g 和有效性掩码，才能计算覆盖、重复映射和前后向循环。

样本类型：第一类是人工确认的正常输出，用于测正常误报；第二类是网络实际生成的输出，用于检验模型指纹和真实分布；第三类是在真实输出上注入已知压扁、折叠、置换、漂移等错误，用于校准探针，但不能当作真实失败证据；第四类是网络自然产生、经人工确认的失败输出，用于建立真实质量标签。只有第三类时，实验只能证明“探针能识别已知注入错误”。

独立质量标签：标注者查看源/目标网格或渲染图时隐藏探针分数和扰动类型，单独填写 sample_label（可接受 / 需要复核 / 明显错误 / 无法判断）、error_type（错配 / 翻折 / 漂移 / 缺失 / 自交 / 其他）、region（眼、鼻、嘴、下巴、其他）、confidence_1_to_5 和备注。对 8 个语义锚点可另填人工对应位置及是否一致。标签完成后才把探针特征合并分析，避免用探针给自己制造真值。

S2 与 S3 的关系：S2 证明探针能稳定计算并对受控错误产生响应；S3 才检验这些信号是否与真实对应失败相关，是否能在身份留出和不同模型设置下减少人工复核量。第一轮先实现统一读取器和少量人工复核，确认真实输出上存在稳定信号后，再训练质量评估网络。

S4

训练质量评估网络 拟执行

以面片/顶点图神经网络或 mesh transformer 聚合局部探针和几何特征，输出多个维度：几何有效性、对应一致性、传递风险、局部风险概率及不确定度。采用样本级和身份级隔离划分，避免同一身份的变体泄漏到测试集。

基线：单一翻折率、E_COMP、landmark 误差、逻辑回归/随机森林、只输入模型身份的基线。神经网络必须证明在这些基线上有增益。

S5

验证人工复核效用与泛化 拟执行

在留出身份、不同表情、不同随机种子以及至少一种不同来源的对应输出上评估。用风险覆盖曲线回答：只复核最高风险的 10% 或 20% 样本时，能找回多少真实失败、漏掉多少严重错误。

目标：证明审核器减少人工检查量，同时把漏检风险控制在预先声明的范围，而不只是提升分类准确率。

03

结果

当前可下的结论：S2 已完成探针定义和受控验证，证明几何、映射完整性及明显锚点错配可以被可解释特征部分检出；真实模型质量和人工复核收益仍待 S3 验证，不能把合成扰动结果写成真实模型预测能力。

3.1 已有依据

Sobolev 论文
提供了在嵌入/浸入空间上定义 Sobolev 度量、路径距离和重参数化商空间的严格框架，并证明特定条件下测地距离不退化。它支持“用形变空间的几何来定义距离”，不支持“该距离等价于对应正确性”。
对应综述
把质量拆成真值误差、局部畸变、几何一致性、双射/连续性、拓扑和可视化/下游用途。它支持多轴评估，而非单一分数。
SSRN 预印本
显示确定性探针可以检测被明确定义的网格缺陷，但感知评分相关性弱、不同特征有交叉响应；几何有效性不能替代人工或语义判断。该文尚未同行评审，且研究对象是生成物体网格，不能直接外推到人脸对应。
既有项目实验
此前 E_COMP 作为优化目标使正确基线被推离，支持将其保留为候选审核信号而不作为对应网络的训练目标。旧报告中的稳定性和扰动结果仍需在真实对应输出、身份留出条件下补足。
S2 探针验证（2026-11-20）
几何/映射探针完成 2,320 条样本验证；新增 8 点语义探针完成 120 个正常对、3,240 条点级扰动和 40 个正常控制。共同刚体不变性通过，明显锚点交换在留出身份上三档均检出；小幅漂移响应弱，官方点暂不能可靠投影到网格面片。S2 的结论是“探针可用且边界明确”，不是“真实模型审核已解决”。

3.2 新方向预期交付物 S3 待实验

方法结果

一组定义明确、可复现的几何与映射探针；一个输出样本风险和局部风险图的审核网络；一个面向人工复核的风险覆盖策略。

论文证据

探针消融、错误类型分析、正常变化误报、模型/身份留出泛化、与简单基线比较，以及人工复核节省量与漏检风险。

3.3 可能的论文贡献边界

若实验通过，可主张：提出针对三维人脸稠密对应输出的多轴质量审核框架，证明局部几何与映射一致性特征能在特定留出条件下预测对应/传递失败，并以风险覆盖实验验证其人工复核价值。
不能预先声称：零翻折保证、全局无自交、拓扑被网络自动学会、无真值质量评价已经解决，或 Sobolev 能量本身就是对应正确性的标准答案。
04

判定标准

进入论文阶段
  • 审核器在身份留出测试上稳定优于 E_COMP、单一翻折率和简单分类基线。
  • 至少一种局部风险图能够定位真实对应或下游传递失败区域。
  • 结果跨随机种子、不同表情和至少两个模型/设置保持一致。
  • 风险覆盖曲线显示可减少人工复核量，同时控制严重错误漏检。
  • 正常刚体变化、合法表情和高曲率区域不会造成不可接受的误报。
停止或收缩
  • 几何探针只能识别人工注入的合成错误，不能预测真实输出质量。
  • 只在随机划分有效，身份留出后性能消失。
  • 拓扑指标恒定，或提升完全由一个简单确定性门禁解释。
  • 审核模型不能比人工 landmark 或单项几何检查提供额外复核价值。
  • 提高召回必须付出大量误报，风险覆盖曲线没有实用操作点。

最小下一步：获取一批真实对应模型输出，完成统一读取、探针重算和少量独立人工复核。先验证探针与真实失败是否有稳定关系，再决定是否训练审核网络。
