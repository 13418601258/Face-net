# 三维曲面对应质量验证探针体系

日期：2026-11-28
对应数据：AST-Face、3DDFA_V2 第一轮输出
对应代码：`code/s1_probes.py`、`code/s2_experiment.py`、`code/self_intersection.py`、`code/s2_point_probes.py`、`code/s3_3ddfa_probe.py`

## 1. 研究对象和总体主张

设源三角网格为 (M)，目标曲面为 (N)，对应算法产生一个映射

\[
f:M\longrightarrow N.
\]

本项目不把所有质量问题压缩成一个加权分数，而是按验证对象分层：

1. **网格结构有效性**：输出网格本身是否是合法、稳定的三角曲面；
2. **映射几何有效性**：源曲面到目标曲面的局部和全局映射是否退化、折叠、跳变、缺失或重复；
3. **语义对应一致性**：解剖位置或其他语义特征是否对应正确。

当前先执行前两层，语义层暂时不作为主要实验目标。几何和拓扑合法只能说明没有发现相应的结构性缺陷，不能单独证明语义对应正确。

## 3. 已保留的现有探针

### 3.1 局部曲面 Jacobian

设参考三角形顶点为 (r_0,r_1,r_2)，目标三角形顶点为 (t_0,t_1,t_2)。定义边向量

\[
e_1^r=r_1-r_0,\qquad e_2^r=r_2-r_0,
\]

\[
e_1^t=t_1-t_0,\qquad e_2^t=t_2-t_0.
\]

在每个三角形上建立参考和目标切平面二维坐标矩阵 (A,B)。分片线性映射的局部微分为

\[
J=B A^{-1}.
\]

该定义只比较两个三角形的局部切平面映射，不使用普通三维行列式。

对 (J) 做奇异值分解：

\[
J=U\Sigma V^{\mathsf T},\qquad
\Sigma=\operatorname{diag}(\sigma_{\max},\sigma_{\min}).
\]

其中：

- (sigma_{\max}) 表示局部最大拉伸；
- (sigma_{\min}) 表示局部最小拉伸；
- (sigma_{\min}) 接近零表示局部压缩或退化；
- (sigma_{\max}) 很大表示局部拉伸。

当前诊断阈值为

\[
\sigma_{\min}<0.5
\quad\text{或}\quad
\sigma_{\max}>2.
\]

这些是固定的诊断阈值，不是经过真实质量标签训练出的分类器。

### 3.2 面积比

参考和目标三角形面积分别为 (A_r,A_t)，定义

\[
\rho_A=\frac{A_t}{A_r}.
\]

因为

\[
|\det J|=\frac{A_t}{A_r},
\]

所以面积比可以看作局部面积放大率。当前诊断阈值为

\[
\rho_A<0.5
\quad\text{或}\quad
\rho_A>2.
\]

它不能单独区分正常表情弯曲和对应错误。

### 3.3 三条边长比

对三条边分别计算

\[
\rho_1=\frac{\|t_1-t_0\|}{\|r_1-r_0\|},
\quad
\rho_2=\frac{\|t_2-t_0\|}{\|r_2-r_0\|},
\quad
\rho_3=\frac{\|t_2-t_1\|}{\|r_2-r_1\|}.
\]

代码进一步保存

\[
\rho_{\min}=\min(\rho_1,\rho_2,\rho_3),
\qquad
\rho_{\max}=\max(\rho_1,\rho_2,\rho_3).
\]

它与 Jacobian 奇异值相关，但直接反映三角形离散边的变化。

### 3.4 法向变化

参考和目标单位法向为 (n_r,n_t)，定义

\[
c=n_r\cdot n_t,
\qquad
\theta=\arccos(\operatorname{clip}(c,-1,1)).
\]

当前报告：

- 法向反转：(c<0)；
- 大法向变化：(\theta>\pi/4)。

法向反转是折叠候选，不是单独的严格折叠证明。它与带符号 Jacobian 和全局自交检测应分开报告。

### 3.5 退化面

目标面片面积满足

\[
A_t\le 10^{-12}\max(1,D)^2
\]

时标记为退化，其中 (D) 是目标网格包围盒对角线。退化面会使局部切平面和 Jacobian 不稳定，因此既是网格结构异常，也是映射几何异常。

### 3.6 全局三角面自交

`code/self_intersection.py` 先使用 BVH/AABB 做宽相位，再用三角形分离轴定理和窄相位几何判断确认候选面片对。共享顶点或共享边的正常邻接面片被排除。

输出区分：

- 严格穿越；
- 共面重叠；
- 接触候选；
- 分离。

它检测的是输出网格的几何有效性，不直接证明对应语义错误。

### 3.7 映射重复和覆盖缺失

S2 中的 `duplicate_mapping` 把局部区域所有顶点的目标索引改为中心顶点索引，用于检验多对一检测；`coverage_missing` 保留坐标不变，只将局部区域标记为无效，用于检验缺失掩码和“不适用”传播。

这两项是离散索引级映射正控，不是目标曲面面积覆盖率的完整实现。

## 4. 新增探针

以下探针超出现有 S1/S2 的主要覆盖范围，建议作为新的扩展模块加入，而不是修改旧探针的定义。

### 4.1 三角形形状质量

对三角形 (T) 定义

\[
q(T)=\frac{4\sqrt3 A(T)}{a^2+b^2+c^2},
\]

其中 (a,b,c) 是三条边长度，(A(T)) 是面积。等边三角形满足 (q(T)=1)，细长或退化三角形的 (q(T)) 接近零。

建议输出：

- 目标网格 (q(T)) 分布；
- 低质量面片比例；
- 最小角和最长边/最短边；
- 相对于参考网格的质量变化；
- 低质量面片空间位置。

所属体系：**网格结构有效性**。

它补充面积比和边长比，因为面积相同的两个三角形可能具有完全不同的形状。

### 4.2 顶点面积密度

对顶点 (v_i) 定义局部面积质量

\[
m_i=\frac13\sum_{T\ni v_i}A(T).
\]

参考和目标之间使用相对比值

\[
r_i=\frac{m_i^{\text{target}}}{m_i^{\text{reference}}}.
\]

建议统计

\[
\operatorname{Std}(\log r_i),
\quad q_{05}(\log r_i),
\quad q_{95}(\log r_i),
\quad \max|\log r_i|,
\]

并输出异常顶点区域。

它检测：

- 局部顶点过度聚集；
- 局部采样变稀；
- 原有采样密度结构被破坏。

不能简单要求整张人脸密度完全均匀，因为眼睛、嘴唇和鼻翼可能本来就有不同的采样需求。

所属体系：**网格结构有效性**。

### 4.3 带符号的二维 Jacobian

当前奇异值只给出拉伸大小，没有给出方向符号。若在源、目标面片建立一致定向的二维切平面坐标，可计算

\[
d_T=\det J_T.
\]

其解释为：

- (d_T>0)：局部方向保持；
- (d_T<0)：局部方向反转；
- (d_T\approx0)：局部退化。

它比单独依赖法向变化更直接地描述局部折叠，但需要明确源、目标面片的定向约定。

所属体系：**映射几何有效性**。

### 4.4 相邻面 Jacobian 跳变

对共享边的相邻面片 (T,T')，比较它们的局部微分：

\[
P_{\mathrm{jump}}
=\sum_{T\sim T'}w_{TT'}
\left\|J_T-\operatorname{PT}(J_{T'})\right\|_F^2.
\]

其中 (operatorname{PT}) 表示将两个面片的切空间坐标转换到可比较的共同坐标系。第一版实现可以先使用共享边局部坐标系比较，之后再加入更严格的平行移动。

它检测：

- 映射在面片边界处突然跳变；
- 局部接缝和折痕；
- 平滑漂移中的异常梯度；
- 单个面片指标正常但跨面片不连续的情况。

所属体系：**映射几何有效性**。

这是当前最值得优先加入的新探针之一。

### 4.5 顶点 link

对顶点 (v)，收集所有包含 (v) 的三角形，并把三角形中除 (v) 之外的邻接顶点按局部连接关系组成 link 图。

合法二维流形应满足：

- 内部顶点的 link 是一个闭合环；
- 边界顶点的 link 是一条区间；
- 不应出现多个独立环、分叉或多个不连通扇区。

它可以发现：

- 两个曲面只在一个顶点相接；
- 局部面片扇区断裂；
- 顶点周围出现多个独立面片簇；
- 边检查不容易单独表达的局部非流形结构。

所属体系：**网格结构有效性**。

但当前 AST-Face 的扰动只改变顶点坐标或映射索引，不改变面片连接关系，因此顶点 link 对当前坐标扰动不会提供新信号。它适合拓扑修改、重网格和点云重建场景，当前作为结构补充而不是主要 S2 探针。

## 5. 目标表面覆盖重数：延后到显式映射模型

对目标曲面 (N) 上的点 (y)，定义覆盖重数

\[
m_f(y)=\# f^{-1}(y).
\]

三种情况为：

- (m_f(y)=0)：目标区域缺失；
- (m_f(y)=1)：一次正常覆盖；
- (m_f(y)>1)：重复覆盖。

可定义缺失面积比例

\[
P_{\mathrm{missing}}
=\frac{1}{A(N)}
\int_N\mathbf 1_{\{m_f=0\}}\,dA,
\]

以及超额覆盖面积

\[
P_{\mathrm{overlap}}
=\frac{1}{A(N)}
\int_N(m_f-1)_+\,dA.
\]

它针对的是：

- 不同拓扑网格之间的显式对应；
- 点云到网格的对应；
- 部分网格到完整网格的映射；
- 重采样或重网格后的映射；
- 神经网络输出的前向/反向曲面对应。

它要求保存真实显式映射，例如：

```text
源三角形 → 目标三角形
源点 → 目标三角形 + 重心坐标
```

AST-Face 当前使用共享顶点索引作为合成对应，3DDFA_V2 主要使用固定 BFM 模板编号。对这些数据直接计算覆盖重数会过度依赖拓扑先验，因此暂不作为当前主线探针。

所属体系：**映射几何有效性**，但延后到显式对应模型阶段。

## 6. 持续拉普拉斯的定位

持续拉普拉斯或持久同调不作为当前固定拓扑网格的基础缺陷检测器。

原因是：

- 移动顶点而保持连接关系不变，不会改变组合拓扑；
- 局部删除面片后仍可能保持同一个圆盘拓扑；
- 零特征值重数不能识别大部分坐标级拉伸、折叠和平滑漂移。

它更适合：

- 点云；
- 拓扑未知或不可靠的数据；
- 重网格结果；
- 多尺度噪声和拓扑变化分析。

因此当前只把它保留为未来的点云/多尺度扩展，不放入 AST-Face 和 3DDFA_V2 的核心探针集合。

## 8. 建议的新增优先级

最值得先实现的四项是：

1. **三角形形状质量**：补足面片形状退化；
2. **顶点面积密度**：补足采样分布变化；
3. **带符号 Jacobian**：直接检测方向反转；
4. **相邻面 Jacobian 跳变**：检测跨面片连续性。

这四项分别补足当前系统的四个空白：

```text
面片形状
顶点分布
方向反转
跨面连续性
```

顶点 link 作为拓扑修改场景的结构补充；目标表面覆盖重数等拿到显式前后向映射后再实现；持续拉普拉斯暂不加入当前固定拓扑实验。

## 9. 结论边界

即使一个映射通过：

- 网格结构检查；
- 局部 Jacobian 检查；
- 面片质量检查；
- 自交检查；
- 覆盖检查；
- 平滑性检查；

也不能推出语义对应一定正确。

存在光滑、双射、无自交、保持边界和保持面积，但内部语义位置发生扭转的映射。因此当前体系应使用以下结论表述：

> 通过几何和拓扑探针，表示没有发现这些探针能够检测的结构性或映射几何缺陷；它不等价于语义对应正确。

这也是本研究的可识别性边界：一部分对应错误可以通过几何和拓扑稳定检出，另一部分错误在缺少独立语义信息时原则上不可由这些探针单独判定。
