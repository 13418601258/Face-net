总览与判据

本计划只覆盖到「试金石实验」为止。此阶段的目标不是做出方法，而是用最低成本回答一个问题：群体描述长度能不能度量点云对应的质量。答案是肯定，才值得投入后面的神经场；答案是否定，结论本身就有价值。

三个阶段之间有严格的依赖关系：阶段 1 依赖阶段 0 的拓扑校验（拓扑不一致，编号相同即位置相同这个前提就不成立）；阶段 3 依赖阶段 2 的单元测试（E_COMP 算错，后面所有曲线都无意义）。所以顺序不能调整。

本阶段不做什么

以下内容明确排除在本计划外，避免范围蔓延：

  • 不训练任何神经网络。
  • 不申请 BU-3DFE / Bosphorus（这是并行事项，不阻塞本计划）。
  • 不追求严格复现 Bolkart 的完整管线。
  • 不制作自交折叠样本（属于后续阶段，混入会污染因果归因）。
  • 不写论文正文，产出的是一份结论与数据表。

S0.3 拓扑校验：证明所有网格共享同一套连接关系 关键

这是整个计划的前提条件。做法是把每个 .obj 的面片索引序列做哈希（或直接逐元素比对），确认全部完全一致。

为什么必须先做这一步：你的「已知真值」完全建立在「所有网格的第 N 号顶点指同一解剖位置」之上。如果某个文件的面片顺序不同，那么它在数值上仍然能被读入、能算出 E_COMP，但那个数值是错的——而且不会报错，只会悄悄污染结论。

S0.4 顶点数比对：AST-Face 与 FLAME 是否同构 关键

AST-Face 的处理管线是 FLAME 拟合 + 边缘约束非刚性 ICP（见其 Scientific Data 论文）。FLAME 的网格是 5023 个顶点。因此先确认一件事：AST-Face 每个网格的顶点数是多少？

如果等于 5023：说明两者同拓扑，后续你可以直接以 FLAME 为模板构造合成验证集，且能与现有数据互通。
如果不等于 5023：记录实际顶点数，后续模板需求另作设计，不影响前三个阶段。

产出
一行结论：顶点数 = ?，是否与 FLAME 同构
验收
结论明确写入记录，不留「大概」
实测结果 · 结论为「不同构」
模型 顶点数 面片数 结论
AST-Face 33390 66190 不同构
FLAME 5023 —

判断依据：33390 / 5023 ≈ 6.65，既非整数倍，也不是标准 Loop 细分的结果（细分两次约 79843 顶点）。故 AST-Face 使用的是独立构建的更密模板；论文所述「FLAME-based fitting」中，FLAME 仅作为初始拟合工具。

影响：阶段 0–3 不受影响；后续构造合成验证集时不得套用 FLAME 拓扑，应改用「AST-Face 自带拓扑 + 人为破坏」的路线。

02 / Phase 1

扰动数据集 · 约 3 天已完成

既然 AST-Face 的对应是数据自带的，那就主动破坏它、制造已知程度的退化。这样才有「标准答案」可以对照。

S1.1 定义扰动类型

实现五种可独立施加的扰动函数：

表 1  扰动类型与破坏对象
类型 做法 破坏的是什么
索引打乱 对顶点编号做置换 仅破坏对应，几何完全不变
坐标噪声 给顶点坐标加高斯噪声 几何精度
平滑局部形变 叠加低频、空间平滑的位移场 逐步破坏对应一致性
随机缺失 随机丢弃部分顶点 数据完整性
全局刚体变换 旋转 / 平移整体形状 作为对照，理想情况下指标应基本不变

最后一行是负对照：刚体变换不改变对应关系，合格的指标应对它不敏感。

S1.2 设定强度等级

每种扰动设 3 至 5 档强度，让量级跨度拉开（例如噪声标准差从亚毫米到数毫米）。档位要能覆盖「指标几乎不动」到「指标明显变差」的完整区间，否则曲线会挤在一端，看不出趋势。

建议先按直觉设一版，在阶段 3 看到结果后回头调整档位——这属于正常流程，不算返工。

03 / Phase 2

评价内核 · 约 7 天进行中

把描述长度算出来。这一步的全部风险集中在一处：算错了不会报错，只会安静地给出错误结论。因此单元测试是硬要求。

执行顺序：S2.1 → S2.2 → S2.3 → S2.5 → S2.4 → 阶段 3。
S2.5 修正的是已经发现错误的部分（真实数据证明指标方向反了），建议优先做；S2.4 与它互不依赖，可并行推进。两者都是阶段 3 的前置条件，都不能跳过：缺 S2.5，指标方向是错的；缺 S2.4，就无法判断「指标变化是否伴随几何破坏」。

S2.1 实现线性 / 多线性分解

把每个形状展平为向量，按样本组织成矩阵（或按身份 × 表情组织成张量），做 PCA 或 Tucker 分解，得到各模式的特征值。

第一版只做线性 PCA 也完全可以——试金石实验检验的是「描述长度能否反映对应质量」，这一点用线性模型就能验证。多线性分解留到需要区分身份/表情时再加。

验收

S2.2 实现 E_COMP

按 E_COMP = sum( log(lambda_i + delta) ) 实现，注意三个细节：

  • 对数的底（自然对数或 2）只需在全文保持一致，差异只是常数因子。
  • delta 必须显式暴露为参数并记录取值，它的作用是防止特征值趋零时结果发散。
  • 特征值要先归一化到统一量纲，否则不同尺度数据的数值不可比。

S2.3 手算单元测试 最关键

构造一个玩具例子：2 个顶点、3 个样本，在纸上手算出协方差、特征值、E_COMP。然后断言代码输出与手算值一致（允许浮点误差）。

再补两个断言，专门验证语义正确性：

  • 排列不变性：把样本顺序打乱，结果必须完全相同。
  • 索引敏感：对某一个形状做顶点置换，结果应当变差（因为对应被破坏了）。

这两个断言一旦通过，你就同时证明了「实现正确」和「指标方向正确」。它们只有几十行代码，但能挡掉后面最贵的返工。

一个同样重要的事实：玩具例子的“通过”是靠秩从 2 降到 1 实现的（维度变化把方向救了回来），并不是靠对应质量。这说明玩具例子不能用来外推判断方向。

据此归纳出三处需要修正的问题，见 S2.5。

S2.4 实现几何健康度指标

至少要能算：表面覆盖率、点到面距离、三角形翻转数量。

它们的作用是充当「对照裁判」。只报描述长度是不够的——必须能回答「描述长度下降的同时，几何有没有被破坏」。这正是防止目标被钻空子的唯一手段。

# 问题 修正 理由
1 计数维度不固定 E_COMP 按固定长度 K = min(N−1, D) 的谱计算，空缺位置补零，交给 δ 承担 项数不同则数值不可比。补零方向也符合信息论：没有变化的方向几乎不占编码代价

S3.4 作出判定 终点

最终判定：部分通过，方向可继续，但原主张需要收窄。E_COMP 对索引对应破坏和坐标噪声具有稳定响应；对平滑局部形变不稳定，不能单独作为保证几何质量的训练损失。

原目标是“仅优化 E_COMP 就能驱动网络获得好的对应”。当前数据不支持这个强结论；后续应改为几何保真约束下的 E_COMP 辅助学习。

带入后续实验的边界：

  • ΔE_COMP / K 只用于同一 cohort 内比较曲线形状；绝对 E_COMP 不跨 N 直接比较。new5 的 K=4，结论应弱于 K=14/19。
  • E_COMP 不得单独优化。网络必须同时加入重建、表面距离、覆盖率或其他几何保真约束，防止通过压缩身份差异获得虚假的紧凑度提升。
  • 后续网络实验必须按身份划分训练、验证和测试，不能随机拆顶点或表情；reference variance 应只由训练身份冻结。ast016–020 已参与 S3.3/S3.5 的方法开发；后续若继续作为留出身份，只能报告探索性泛化，不能称为从未查看的确认性测试集。

对论文主张的修正：不再声称 E_COMP 单独就是通用对应损失，而是将其定位为在几何约束下促进跨身份一致性的候选辅助信号。这样保留了“驱动网络学习对应”的目标；能否抑制几何塌缩和过度平滑，以及是否改善留出身份的对应，仍需实验验证。

下一步：先完成几何约束与身份留出协议，再比较“几何损失”“E_COMP 单独”和“几何损失 + E_COMP”三种网络基线；当前结果支持继续研究，不支持直接进入 E_COMP-only 训练。

一句话结论

失败的是「把群体紧凑度当作可优化的目标」，成功的是「把群体紧凑度当作评估对应质量的指标」。两者用同一个数、同一套代码，方向相反。

一 · 为什么「驱动」这条路不行

机制级原因：E_COMP 度量的是「群体有多紧凑」，它的极小点是「所有形状挤成一团」，而真值天然不是它的极小点。零谱解 −393.74，正常基线 −96.55——塌缩解比正确答案好 297 分。这不是实现缺陷，是定义决定的，所以换参数化、调权重、加门控都救不回来。

二 · 还获得了什么

1 · 一个可用的评测指标（正面资产）

同一批数据里，E_COMP 作为评测指标的证据强度反而更高，而且是罕见的干净结果：「在没有正确答案的条件下判断对应质量」本身就有用——配准评估通常需要稠密真值，而真值恰恰最难拿到。这条线不需要网络、不需要 landmarks、不需要训练。

2 · 一个可发表的机制结论

「为什么配准领域普遍用几何损失，而不用统计紧致度？」——现在有定量答案而不是直觉：紧致度的极小点与对应正确性无关；真值处梯度非零且推离量级大于拉近量级；约束最紧的位置不在塌缩终点，而在部分塌缩的「肩部」（t ≈ 0.8 处所需 λ 最大 1.5062，而那时分数已掉 8.5、几何损失才 0.65）；权重越大越差，不是单调有益。

3 · 方法论上可复用的结论
  • 判据必须按扰动类型分开。同一条「破坏越重、指标越差」，在对应关系类扰动上 252/252 成立，在几何类上不成立。合并成一条会得出错误结论——这是阶段 3 判定必须拆成 C1a / C1b 的原因。
  • 方向判定要用噪声相对阈值，不能用绝对阈值。21 条「反例」是用 change < −1e−8 判出来的，它们的 |ΔE_COMP| 全部 ≤ 0.23，而在同扰动的高档是 6.08。改成「> 2 × 种子 SD」后归零。这条适用于任何扰动实验。
  • 「可检出」≠「可微」≠「可训练」。T3/T4 很强（0.1% 可检出、恢复路径完全单调），但它们是离散置换序，不提供连续梯度。S3.6 证明这个跳跃是危险的：离散上完美单调，连续上一步就把真值推离。
  • 「真值处驻停性」必须单列为第一门禁。v1 的常规门禁几乎全过——方向 209/210、能量下降 210/210、方差 210/210——唯独真值被推离暴露了根本问题。
  • 门禁要有分辨力，否则是空跑。方差项三档阈值（0.99 / 0.995 / 0.999）全部 210/210 通过；全局覆盖率恒在 99.95% 以上。几何信号其实在局部——144/210 个条件存在局部法向反转，受影响面片内最高 14.13%。
  • 零空间诊断比多跑几轮更有效。算设计矩阵的秩、条件数、零空间维度，直接分析「优化会往哪里跑」。靠这个在一步之内定位了「锚点残差为零但对应仍错」的 21/21 可行解。
  • 参数化维度与观测秩的两难。零空间维度 d − r = 0 时指标没有话语空间，无增益可言；d − r > 0 时指标在零空间里钻空子，净负。这不是 E_COMP 特有的问题，是任何附加正则项都会遇到的。
  • 门控不能用「观测拟合程度」当开关。双向失灵：两个原锚点在最优解处门控关闭但对应仍错，六个分散锚点门控开着却不能驻停。问题在观测量语义，不在阈值。
  • 第三方 landmarks 不能直接当约束。坐标尺度与网格相差约百倍；landmarks 本身参与过原始注册，不构成独立解剖精度；发布侧缺 per-sample 变换参数。
