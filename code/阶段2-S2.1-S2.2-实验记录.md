## S2.1 线性 PCA

实现文件：code/model.py

实现约定：

1. 输入数组第 0 维是样本，其余维度展平为特征向量。
2. 先减去样本均值，再对中心化矩阵做 SVD，不显式构造高维协方差矩阵。
3. 特征值按 singular_value² / (n_samples - 1) 计算。
4. 相对容差默认 1e-10，数值上为零的方向剔除，因此保留的特征值均为正并按降序排列。
5. 支持投影、指定主成分数重构和均方重构误差。

真实数据运行：

- 输入形状：105 × 33390 × 3
- 来源：15 个身份 × 7 个阶段 1 状态
- 保留正特征值数：104
- 前 5 个特征值：

    49.16395833, 37.96636980, 15.75722950, 10.47971631, 7.42182592

重构误差随主成分数增加：

    主成分数  1          2          4          8          16
    MSE       9.795e-4   6.041e-4   3.447e-4   1.520e-4   5.237e-5

该结果满足误差单调下降、特征值为正且降序排列。

## S2.2 E_COMP

实现文件：code/ecomp.py

定义：

    E_COMP = sum(log(lambda_i + delta))

实现约定：

- 默认使用自然对数；
- delta 显式暴露，默认值为 1e-12；
- 输入特征值默认先除以特征值总和，得到无量纲谱；
- 支持 base=2 输出 bit 形式；
- 支持固定特征值下计算多个 delta 的敏感性。

真实 AST-Face PCA 谱的默认结果：

    E_COMP = -840.2157650585651

玩具谱 [4, 1, 0.25] 的 delta 敏感性：

    delta       E_COMP
    1e-12       -4.9746842298
    1e-6        -4.9746566675
    1e-2        -4.7198559701

固定输入下结果可复现；delta 增大时 E_COMP 单调上升，符合显式平滑项的数学性质。

## S2.3 手算单元测试

实现文件：code/test_ecomp.py

玩具数据为 3 个样本、每个样本 2 个顶点：

    [0, 0], [1, 0], [0, 1]

中心化后的协方差矩阵为：

    [[1/3, -1/6],
     [-1/6, 1/3]]

手算特征值为：

    lambda = [1/2, 1/6]

归一化谱为 [3/4, 1/4]，因此测试中的理论值为：

    E_COMP = log(3/4 + delta) + log(1/4 + delta)

测试覆盖：

- 手算协方差特征值与代码输出一致；
- 手算 E_COMP 与代码输出一致；
- 打乱样本顺序不改变特征值和 E_COMP；
- 只交换一个样本的两个顶点后，特征谱和 E_COMP 发生变化，且 E_COMP 变大；
- 测试通过：3/3。

### 实现过程中遇到的困难与处理

1. code 目录不是 Python package，直接使用 from code.model import ... 会被 Python 内置 code 模块遮蔽。测试文件改为把自身目录加入 sys.path，再导入 model 和 ecomp。
2. 顶点置换后的方向需要先固定。测试选择 [1, 0] 这一行交换为 [0, 1]，这样可以手算出退化为单一主方向，避免只断言“有变化”而无法判断方向。
3. PCA 的 SVD 特征向量符号本身不唯一，因此测试不比较主成分向量，只比较特征值和 E_COMP；这些量对 SVD 符号不敏感。
4. E_COMP 使用归一化特征值，且 delta 显式设为 1e-9，使手算公式与实现完全对应，同时避免零特征值取对数的问题。
