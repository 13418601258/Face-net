# S3.6 v2 机制试验结论（2026-10-19）

执行决定方向合理，但“空间平滑 + 稀疏锚点 + 门控”还不足以保证正确对应。该结论限定于本轮低维场与代理锚点，不否定所有网络或所有对应约束。用户 HTML 未修改。

已执行七状态、三种子、五档初始滑移、四组对照，共 420 次闭环运行、8400 条逐身份终点、60328 条轨迹记录。全部 21 个调和曲面坐标有效，所有已接受迭代无受影响面片法向反转且面积比满足保护条件。几何仍未检查全局自相交。

| 组别 | 84 个正强度条件中较初始改善 | 非锚点 NRMSE 相对降低中位数 | 21 个正确基线发生漂移 |
|---|---:|---:|---:|
| 代理锚点 only | 84/84 | 83.920% | 0/21 |
| 锚点 + 固定紧凑项 | 84/84 | 82.660% | 21/21 |
| 锚点 + 门控紧凑项 | 84/84 | 83.915% | 0/21 |
| E_COMP-only | 24/84 | -27.512%（中位数变差） | 21/21 |

这些是固定迭代预算的终点，不是普遍收敛结果：373/420 次达到 160 次迭代上限；47 次达到梯度阈值，其中包括 42 次锚点/门控组的正确基线。

核心证据来自另外的解析与事后探针检查：

- 21/21 组都存在几何可行、稀疏锚点误差数值为零、非锚点对应仍有误差的解。每身份 6 个系数，两个锚点仅提供秩 4 的约束。该证书由稀疏设计矩阵的零空间求出，不依赖优化是否跑完。
- 固定锚点，沿剩余自由方向下降 E_COMP：在正确基线处 21/21 能量下降而对应变差；在上述零锚点残差解处 8/21 改善、13/21 变差。全部探针保持锚点残差 < 8e-32，并通过同样的局部几何检查。
- 因此门控在零锚点残差时停住是构造性质，不是恢复正确对应的证据。平滑场和局部几何保护也未消除紧凑项在真值处的偏移。

联合组的附加收益尚不能据此定论：在 t=1 初始点，加权紧凑项梯度/锚点梯度的中位数仅约 1.04e-4，lambda=0.1 只是声明的探索值。固定组仅 30/84、门控组 33/84 的配对终点优于锚点-only，且门控组的差异极小。不能把改善主要来自锚点写成紧凑项有效，也不能由当前弱权重否定其他权重。

本轮没有可直接使用的独立锚点：抽查的原始 landmark 与标准化网格坐标尺度不一致，未擅自估计变换。使用两个 AST 标准对应代理锚点/身份是合成机制测试；现有 all20 GPA 和公共曲面坐标也属于基准条件，不是完整部署流程。

下一步先验证 landmark 的坐标变换和模板附着，再检验对应约束是否覆盖场的自由方向。随后单独冻结梯度尺度标定、收敛预算及留出协议，比较受约束闭环。不要直接增加 MLP 容量、以真值误差决定门控，或把增加代理锚点后可唯一恢复写成 E_COMP 的贡献。
