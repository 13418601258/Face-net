# S3.6 第一关执行决定复核（2026-10-19）

结论：先改空间参数化、增加对应约束、改为不依赖真实误差的步长，再做非神经闭环，这个顺序合理。本轮执行机制试验，不修改用户 HTML，也不将它自动升级为网络放行证据。

本轮落实：

- 原始连接上的局部调和坐标，用分片重心插值实现跨三角片滑移；6 个空间平滑系数/身份，共 120 个系数。紧支撑覆盖所有内部顶点并在边界衰减。
- 每次接受更新都检查受影响面片的法向和面积比，不用接近 100% 的全局覆盖率代替局部检查；这仍不能证明没有自相交。
- 比较代理锚点 only、代理锚点+固定紧凑项、代理锚点+门控紧凑项、E_COMP-only。增加锚点 only 是为了区分改善来自何处。
- 系数步长上限与 Armijo 回溯依赖梯度、目标和几何可行性，不依赖真实对应误差。停机记录梯度/步长/回溯失败/迭代上限，后两者不自动等于正确收敛。
- 保留 t=0、0.05、0.1、0.5、1；t=1 是本次生成的连续滑移起点，并非离散索引置换。各路径实际位移另报。

必须限定的地方：

1. AST landmark TXT 与标准化 OBJ 的坐标尺度不一致。抽查 ast001 的 au0/happy：网格对角线约 2.24/2.30，landmark 点集约 216.98/217.82；不能直接叠加，也未找到经过验证的坐标变换与模板附着关系。不得编造转换。本轮改为明确标注的两个精确稀疏代理锚点/身份，它们来自 AST 已有标准对应，属于合成弱监督机制试验，不是独立解剖锚点。
2. 两个锚点提供 4 个标量约束，6 个系数仍有不可观测方向。零锚点误差和停止不等于整片对应正确；另作解析零空间诊断。
3. 门控按 g=A/(A+1e-4) 缩放紧凑项梯度，单次回溯冻结 g。它是状态依赖更新规则，不冒充 A+lambda*g(A)*E 的完整梯度。
4. 固定 lambda=0.1 是本轮声明的探索值，不来自 T5。必须报告实际梯度比例，不能用联合组差异很小就否定紧凑项；改变权重应另立协议。
5. 多步试验只能同时检验当前损失、低维参数化、锚点和求解器，并没有剥离成“只剩损失本身”。不预先承诺几十分钟或相对网络的固定耗时倍数。
6. 单独的保真项在真值处驻停，不保证与固定正权重 E_COMP 相加后仍驻停。以锚点残差门控可构造基线驻停，但还需要证明非锚点恢复与独立锚点有效性。

第一次平面投影试跑在任何优化前因 happy/seed0 的局部三角片投影反转而退出，保存在 ../stage3_s36_v2/。随后改为调和坐标并重新冻结到当前目录，未删除失败状态或挑选有利路径。

最终计数与效果见 summary.json、mechanism_diagnosis.json、verification.json。主试验与事后诊断各自保存来源哈希。数据和代码验收通过不意味着网络放行。
