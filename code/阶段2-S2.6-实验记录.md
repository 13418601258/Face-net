# S2.6：刚性 GPA、尺度与缺失数据协议

日期：2026-10-18。配置版本：`rigid-gpa-v3`。本记录对应用户补充的 S2.6；实验结果单独写入 `reports/protocol_v3/`，保留 v2 原始结果。HTML 不作修改。

## 采用的处理决策

用户已确认：保留个体尺度，GPA 只去除旋转和平移；含缺失坐标的样本组只报告几何指标，E_COMP 标记不适用，不补值。

样本范围为已解压的 ast001–015、au0/angry/disgust/fear/happy/sad/surprise 七个状态，共 105 个网格。沿用 S2.5 的七状态范围，本次不包含另外九种 AU 状态，也不读取压缩包。

`preprocessing.rigid_gpa` 对每个状态的 15 个形状共同处理：

1. 分别减去每个形状的顶点均值，以第一个已中心化形状初始化均值。
2. 使用 Kabsch 求解行向量约定下的最优旋转，将每个原始中心化形状对齐到当前均值；强制 det(R)=+1，禁止镜像，不求缩放系数。
3. 更新均值，用全组共同旋转固定均值的全局朝向。这一步不改变群体谱，也不改变任何形状内部距离。
4. 均值相对 Frobenius 变化 ≤ 1e-9 时停止，最多 100 次；未收敛会使验收失败。保存实际迭代次数、目标值、中心和旋转。

每次扰动后重新执行同一 GPA 协议。该过程依赖候选对应关系，因此必须回归检查索引错误的响应；不能仅凭姿态不变性认定方案有效。

## 固定计分与基线解释

仍使用自然对数与固定完整谱长度 K=14：

    E_COMP = sum_{i=1}^{14} log(lambda_i / reference_variance + 1e-9)

参考方差来自七组未扰动数据分别 GPA 后的 105 个形状，合并计算协方差迹并冻结。扰动、种子和强度都不会重新估计这个值；零特征值保留。额外导出 delta=1e-6、1e-3 下的分数变化。

固定除数不会逐组消除尺度差异，GPA 也不缩放个体。因此尺度信息仍保留。分数依然可能受真实大小差异影响，这是本次选择的含义；不因此获得跨队列、跨单位的直接可比性。

计划中“基线基本不变”需要区分：

- 同一未扰动数据重复执行同一 v3 预处理，分数应保持一致，代码对此设有门槛。
- 原始坐标换成 GPA 坐标，协方差及分数可以变化；这不是数值重复性。`baseline_comparison.csv` 同时交叉记录原始/GPA 坐标和 v2/v3 参考方差，单独给出固定参考方差下的对齐影响。
- 不能用参考方差更换抵消基线漂移后宣称原始基线未变，也不能将本轮程序验收通过等同于 HTML 中这句话的字面验收通过。

## 扰动和几何比较

索引回归为 7 状态 × 3 模式 × 3 种子 × 5 强度（含零）=315 行。零强度共 63 行是曲线起点的重复记录，并非 63 个新增实验样本。共同置换检查谱不变；单样本和独立置换逐状态、逐种子检查正响应和非降趋势。独立置换另外检查 GPA 后响应/原始响应 ≥0.5，这是本次配置中的工程验收下限；实际保留比例也会报告。

刚体回归为 7 × 2 模式 × 3 种子 × 3 强度=126 行。共同刚体严格对所有形状应用相同 R、t，独立刚体使用身份派生随机流；使用 float64。强度为 0.25/0.5/1，每个欧拉角采样于 ±15°×强度；每个平移分量采样于 ±0.5×全组中心化坐标 RMS×强度。这里的坐标 RMS 为 sqrt(mean(x_centered²))。本轮刚体随机流和幅度定义与旧临时探针不同，不能要求未对齐分数精确重现 +30.6；应比较同一批候选处理前后的响应。

噪声、局部平滑形变、随机缺失各 7 × 3 × 4=84 行，共 252 行，分别使用配置中的四档强度。噪声标准差为强度×网格包围盒对角线；局部形变最大幅度按同一对角线设定，默认高斯作用半径为对角线的 0.22，沿用 perturb.py 的定义。噪声/形变由已有 float32 扰动函数生成，随后以 float64 对齐与计分。

含 NaN 的 84 个缺失组不进入 GPA/PCA/E_COMP：CSV 的 score/change 为空，status=`not_applicable_missing_coordinates`；不把缺失分数记为零。保留有效顶点掩码，删除含无效顶点的候选面片后计算覆盖率和距离。该实验只施加缺失，没有额外姿态扰动，几何比较在原始共同坐标系完成；尚不涵盖“缺失+未知姿态”的组合。

几何指标覆盖 ast001 的七状态，7 个基线+126 个刚体+252 个几何扰动=385 行。每个方向按面积采样 2048 个表面点，对每点求最近三角面距离；覆盖阈值为参考网格包围盒对角线的 0.1%。有限完整候选经 GPA 后，再施加一次全组共同旋转平移以统一比较坐标系。刚体验收要求覆盖率=1、法向反转=0、对称平均距离/覆盖阈值 ≤1e-5。

E_COMP 属于 15 身份群体统计，几何指标只属于指定身份；两者的相反变化是诊断线索，不是全体几何恶化的证明。法向反转数也不是自交检测。

## 尺度诊断修正

旧 `check_scale.py` 的 `(X[i]-X[i].mean(0))/diags[i]*dmean` 同时做了中心化和尺度调整。因此原文“尺度差异贡献 41%”不能直接作为尺度单因素贡献。

本轮 `scale_ablation.csv` 按原始坐标、只中心化、刚性 GPA、GPA 后统一 RMS 半径四步报告协方差迹。统一半径只用于诊断，不进入实际计分。后两步的差值是这套顺序及归一化定义下的变化，仍不应宣称为唯一的因果方差分解。

### 几何扰动的负结果

84 组坐标噪声的 ΔE_COMP 均为正，范围 +0.00324～+5.96588。84 组平滑形变的范围为 **-0.22630～+4.09586**，其中 **21 组为负**；这些组的 ast001 表面距离同时非零，全部保存在 `geometry_score_disagreements.json`。

一个明确例子：surprise、seed=0、平滑形变强度=0.01，ΔE_COMP=**-0.22630**，ast001 覆盖率由 1 降为 **0.52686**，对称平均表面距离变为 **0.0023460**。这支持“紧凑度改善不保证代表样本几何保真”的判断；由于几何只测 ast001，不能据此宣称全部 15 个身份的几何都恶化。距离沿用网格坐标单位，未确认其为毫米。

84 个缺失组均正确保持分数为空。以 seed=0、缺失 20% 顶点为例，七状态覆盖率为 0.6367～0.6924，仍可用于几何比较；不将空分数加入分数均值或排名。

## 阶段 3 的使用边界

本轮对照若通过，支持继续做阶段 3 的受控比较，不意味着可以直接训练神经网络。后续应把几何评价扩展到全部 15 个身份，再按群体汇总覆盖率、距离和法向反转，与群体 E_COMP 对照；补充身份划分或留出身份的稳定性验证。同一批身份的七种表情和三个扰动种子不能替代独立身份验证。

计划 C2 的索引敏感性只能证明“能响应这类对应破坏”，不能单独证明“只度量对应质量”。同样，当前尺度保留策略避免了预处理删除大小信息，但不能阻止一个可自由改变几何的网络压缩身份差异来降低 E_COMP。极端情况下所有输出形状相同，全部特征值为零，E_COMP 达到 14×log(1e-9)，仍会奖励塌缩。因此若将来用于训练，必须另行约束几何保真，并验证优化后的结果是否钻了紧凑度目标的空子。

## 复现和产物

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s code -p 'test_*.py' -v
.\.venv\Scripts\python.exe code/validate_protocol.py
```

主要产物位于 `code/reports/protocol_v3/`：

- `reference.json`：完整配置、样本来源、输入数组哈希、核心代码哈希、固定参考方差和维度。
- `scores.csv` / `geometry.csv`：全部群体分数和指定身份几何指标。
- `alignment_log.csv` / `transforms.npz`：收敛记录和 GPA、注入刚体的变换参数。
- `baseline_comparison.csv` / `scale_ablation.csv`：基线变化和分步尺度诊断。
- `acceptance_checks.csv` / `monotonicity.csv` / `summary.json`：逐项验收及汇总。
- `spectra.npz`：完整计分谱；`geometry_score_disagreements.json`：负分数变化但代表样本表面距离非零的诊断记录。
- `permutation_regression.png/.pdf` / `pose_regression.png`：回归曲线；三种子范围不是置信区间。

旧 v2 可用 `--config code/protocol_config_v2.json --output-dir code/reports/protocol_v2_replay` 复现。没有重写旧 6300 个扰动 NPZ；v3 从已解压 OBJ 在内存中确定性生成扰动，结合配置、随机流和哈希复现。

## 实施中发现的问题

首次完整运行在几何行导出时发现 seed 重复传入。已修复，并增加实际运行小型合成网格全流程的集成测试，检查结果行数、几何验收、缺失分数为空及变换文件导出。29 项单元/集成测试通过。

此前把每个网格调用同 seed 的旧 rigid_transform 当作共同刚体不严谨：该函数围绕各自中心旋转，平移还按各自包围盒尺寸缩放，最终不一定是同一个 R、t。本轮使用组级刚体生成器，明确保存并验证共同 R、t。
