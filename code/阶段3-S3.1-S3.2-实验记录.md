## 实验单位及结果表

七状态分别为 au0、angry、disgust、fear、happy、sad、surprise；每个状态的 E_COMP 使用 15 个身份、固定 K=14、reference_variance=111.74964914610983、delta=1e-9。没有新增身份或改变原计分参考。七状态不包括另外九种 AU 状态。

原分数表中的 63 行零强度记录，按“状态×种子”合并为 21 个 baseline，不再按 common/single/independent 重复计为独立实验。保留全部 630 个非零强度实验，合计 651 行；每行的 15 个身份共形成 9,765 行几何明细。

84 个缺失实验仍保留完整行，分数字段为空且 status 明确为不适用；这些空值不是漏算，不参与 E_COMP 均值和曲线。缺失图面板注明不适用，而几何图照常绘制。

## 几何定义、对齐和加速

噪声、平滑形变和刚体候选重放已保存的 GPA，再统一全组坐标系，沿用 v3 的比较方式；缺失数据只施加缺失，在原坐标系比较。完整数据的重放谱及分数会与 v3 逐实验核对。

索引置换在原坐标系进行表面恒等检查：每个顶点置换 p 都构造 `inverse=argsort(p)` 映射面片，并检查 `y == x[p]`、`p[inverse[faces]] == faces`。这保证三角形连接的是原来同一组空间点，绕序和面片身份也保留。通过后覆盖率=1、距离=0、法向反转=0，可用数学恒等结果而不重复采样。`distance_method` 明确标记恒等验证，`sample_count=0`；不会把解析结果冒充 2048 点的数值测量。baseline 同样是表面自身比较。

索引扰动的几何检验针对表面本身，不将错误对应引起的 GPA 刚体偏移当成表面破坏。索引 E_COMP 仍完整执行 v3 GPA 后计分。两者的坐标系分别写在表内，不能将索引几何行解释成“错误对应下 GPA 后的空间定位误差”。

其他几何指标继续使用每个方向 2048 个面积均匀采样点；覆盖阈值为参考形状包围盒对角线的 0.1%，距离使用原网格单位。法向反转不是自交检测。

新加速按三角形外接质心球半径分组，对每组分别用“当前最近距离+该组最大半径”查询 KD 树，再计算真实点到三角面距离。此界保留所有可能更近的面片；不截断近邻数、不改成最近顶点距离。已通过混合大小三角形的暴力搜索对照、旧几何算法对照及真实网格抽测。单个真实噪声网格的抽测耗时由约 1.14 秒降至 0.38 秒；这只是该网格的测量，不是全数据运行时间承诺。

## 图表阅读方式

- `ecomp_curves.png/.pdf`：图一，扰动强度→绝对 E_COMP。八个面板覆盖三类索引置换、两类刚体、坐标噪声、平滑形变和缺失；缺失面板注明不适用。
- `geometry_curves.png/.pdf`：图二，三行分别为平均覆盖率、平均表面距离/覆盖阈值、平均法向反转率，八列与图一扰动类型对应。
- `ecomp_delta_curves.png/.pdf`：补充图，以相同 v3 baseline 为零点显示 ΔE_COMP，便于比较响应和辨认负变化。
- `geometry_perturbations.png/.pdf`：图二中噪声、形变、缺失三个非平凡面板的放大版，便于阅读细节。

最终图表由 `plot_stage3.py` 直接读取曲线统计表重绘；旋转横轴刻度以避免零点与小强度标签重叠，关闭覆盖率轴的偏移显示。`figure_manifest.json` 记录作图 CSV、计算清单、独立绘图脚本及八个 PNG/PDF 文件的哈希，不改变实验值。宽幅完整几何图适合打开 PDF 放大查看。

每种状态独立一条曲线，点是三个种子的均值，误差棒是三个种子的样本标准差（ddof=1），不是置信区间；不混合表情间差异或把 15 个身份重复计入误差棒。恒等对照的误差棒为零，小于标记尺寸的误差棒不人为放大。横轴使用各类扰动的真实强度刻度：索引/缺失为顶点比例，噪声/形变为包围盒对角线比例，刚体为配置中的无量纲强度。不同类型的同一数值不代表相同物理扰动。

### 单向性观察：21 组分数下降但几何偏离

共 21 组平滑形变实验触发分歧记录，各组的 **15 个身份全部出现超过 1e-8 的表面距离**。这将 S2.6 中仅基于 ast001 的诊断扩展为本队列全部身份的检查；“非零表面距离”不等于每个身份覆盖率都下降，应同时阅读覆盖率和距离。

| 状态 | 分歧实验数 |
|---|---:|
| au0 | 1 |
| angry | 4 |
| disgust | 3 |
| fear | 4 |
| happy | 2 |
| sad | 1 |
| surprise | 6 |

最明显的一组为 `surprise_smooth_local_deformation_independent_0_0.01`：

- ΔE_COMP = **-0.22630**；从紧凑度单独看似乎改善。
- 全身份平均覆盖率从 **1** 降至 **0.69258**；各身份范围 **0.52686～0.88232**。
- 全身份平均对称表面距离为 **0.0019411**，各身份范围 **0.0012202～0.0024054**，单位沿用原网格坐标。

这构成当前受控实验中的明确反例：E_COMP 下降不能单独保证原始表面保真。现阶段适合继续 S3.3 的稳定性分析，以及 S3.4 的限定条件判定，不能直接把“数据和图表齐全”转述成“可作为独立神经网络损失”。

## 复现

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s code -p 'test_*.py' -q
.\.venv\Scripts\python.exe code/stage3_analysis.py --workers 6
.\.venv\Scripts\python.exe code/plot_stage3.py
```

默认写入 `code/reports/stage3_v3/`。相同代码与输入下再次运行可使用断点；不会重跑已完成的几何实验。不能在改变配置或代码后把新旧结果混入同一目录，应另用 `--output` 指定目录。

已有完整结果只想重新绘图时，单独执行最后一条命令即可，无需读取网格或重做几何计算。完整计算器会生成基础图；第二条绘图命令输出本记录展示的最终排版和单独的图表来源清单。

本轮完成范围为 S3.1/S3.2。S3.3 的身份稳定性尚需另做身份划分或留出验证，不能因已有 15 个身份的几何指标就标为完成。S3.4 的最终判定和神经网络训练有效性也不在本轮自动通过。
