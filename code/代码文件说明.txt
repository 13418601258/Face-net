audit_io.py
作用：统一读取已解压的 AST-Face 网格、形变和关键点，提供哈希及无反射刚体变换。
如何使用：在 code 下的 Python 程序中导入 ASTFaceReader、read_obj 或 rigid_transform。
输出什么：原始顺序的数组、资产路径、哈希或旋转和平移参数，不改写数据。

run_quality_s0.py
作用：执行 S0 数据登记、基础完整性检查及身份划分，固定审核输入约定。
如何使用：在项目根目录运行 python code/run_quality_s0.py；可用 --protocol 指定协议，--output-dir 指定输出目录。
输出什么：code/reports/quality_audit_s0 下的资产清单、逐样本检查、协议、身份划分、可逆变换和运行记录；PASS 返回 0，需要复核返回 1。

test_quality_s0.py
作用：验证读取器、拓扑哈希、刚体变换和边界检查的关键约束。
如何使用：在项目根目录运行 python -m unittest discover -s code -p test_quality_s0.py -v。
输出什么：测试通过或失败的终端记录。

s1_probes.py
作用：对中性脸到表情网格计算局部曲面 Jacobian 奇异值、面积比、边长比、法向变化、退化统计和可选的 AABB 相交候选。
如何使用：在项目根目录运行 python code/s1_probes.py；默认计算中性脸和六种基本表情，可加 --all-states，或加 --collision 运行候选筛查。
输出什么：code/reports/quality_audit_s1 下的逐样本探针、压缩面片数组、候选相交表、S1 汇总和运行哈希；覆盖率与循环一致性在缺少前后向映射时标记为不适用。

test_s1_probes.py
作用：验证刚体、面内缩放、弯曲法向变化和退化三角形的 S1 指标行为。
如何使用：在项目根目录运行 python -m unittest discover -s code -p test_s1_probes.py -v。
输出什么：测试通过或失败的终端记录。

self_intersection.py
作用：对三角网格使用 BVH 包围盒树和三角形分离轴测试筛查非相邻面片自交。
如何使用：由 run_self_intersection.py 调用；小网格可直接调用 detect_self_intersections(vertices, faces)。
输出什么：穿越、共面重叠、接触候选的面片对，以及 BVH 节点和候选数量。

run_self_intersection.py
作用：对已解压 AST-Face 网格批量执行自交候选检测并导出面片索引。
如何使用：在项目根目录运行 python code/run_self_intersection.py；可用 --subjects、--states 限定样本。
输出什么：code/reports/quality_audit_s1/self_intersection 下的逐网格统计、相交面片对、汇总和运行哈希。

test_self_intersection.py
作用：用已知相交、共面重叠、不相交和共享边样例验证检测器。
如何使用：在项目根目录运行 python -m unittest discover -s code -p test_self_intersection.py -v。
输出什么：测试通过或失败的终端记录。

s2_experiment.py
作用：在已知索引映射上注入局部压扁、折叠、顶点置换、平滑漂移、重复映射和覆盖缺失，评估几何及映射完整性探针。
如何使用：在项目根目录运行 python code/s2_experiment.py；可用 --seed 固定随机种子、--subjects 限定身份。
输出什么：code/reports/quality_audit_s2 下的逐样本指标、六类探针区域定位、强度曲线、合成自交检查和运行哈希；缺失映射时几何/对应误差记为不适用。

test_s2_experiment.py
作用：验证六类 S2 扰动的可复现性、定位标签、映射覆盖率、误差适用性及 Jacobian 数值一致性。
如何使用：在项目根目录运行 python -m unittest discover -s code -p test_s2_experiment.py -v。
输出什么：测试通过或失败的终端记录。

s2_point_probes.py
作用：把官方 84 点中的 8 个解剖锚点接入 S2，计算尺度无关的两两距离和刚体残差语义探针，并验证交换、漂移、缺失三类点级扰动。
如何使用：在项目根目录运行 python code/s2_point_probes.py；可用 --seed 固定种子、--subjects 限定身份、--output-dir 指定报告目录。
输出什么：code/reports/quality_audit_s2_points 下的锚点定义、正常点探针、扰动正控、刚体/自比较控制、网格投影诊断、稳定性汇总和运行哈希。

test_s2_point_probes.py
作用：验证点探针对共同刚体变换不变、对交换与漂移有响应，并明确记录缺失点而不补值。
如何使用：在项目根目录运行 python -m unittest discover -s code -p test_s2_point_probes.py -v。
输出什么：测试通过或失败的终端记录。

official_pipeline_reconciliation.py
作用：按 AST-Face 官方 01–07 流程说明核对当前公开派生数据的阶段、拓扑、形变场和关键点异常。
如何使用：在项目根目录运行 python code/official_pipeline_reconciliation.py。
输出什么：code/reports/quality_audit_s0/official_pipeline_reconciliation.json，说明哪些官方阶段可复核、哪些中间数据缺失，以及需要人工复核的关键点异常样本。

prepare_s3_official_manual_template.py
作用：为官方公开流程导出的最终 Standardized Meshes 生成不依赖关键点坐标换算的人工稀疏点标注表。
如何使用：在项目根目录运行 python code/prepare_s3_official_manual_template.py。
输出什么：code/reports/s3_manual_pilot/manual_sparse_pairs_official.csv，包含开发/留出身份的中性到表情网格路径、8 个语义锚点和待填写的人工坐标与标签。
